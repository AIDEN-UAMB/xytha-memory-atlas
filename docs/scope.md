# 公开边界

此仓库为独立编写的公开示例，不是生产项目的目录裁剪或源代码镜像。

| 公开 | 保留在正式项目 |
| --- | --- |
| 记忆归档的示例格式与校验 | 生产存储适配、迁移、账号验证 |
| 六层标签检查与时间选择交互 | 确定性排盘与完整流耀计算 |
| 来源原文、概述与反馈的关联 | 概述生成提示、模型调度与恢复机制 |
| 宫位图与显式筛选 | 偏好推断、权重、个性化评分和筛选策略 |
| 人工编写的合成角色与对话 | 实际用户资料、对话、记忆和反馈 |
| 零依赖静态演示 | 服务端代码、部署地址、凭据及运维材料 |

公开包不包含生产 Git 历史、数据库、运行日志、账户信息、模型密钥或服务器配置。项目入口仅链接公开的 Xytha 产品网站。

本仓库的代码与原创示例采用 MIT。生产项目及未包含的算法不因该许可证而获得任何授权。设计方案能否构成科学贡献，需要独立的研究与证据；本仓库不作首创或效果保证。
