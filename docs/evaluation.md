# 一份尚未实施的评估计划

**状态：研究设想，没有实验结果。** 合成演示只能验证实现是否按约定运行，不能证明对真实用户有效。

## 可检验的问题

在保留问题语义、明确偏好、上下文时间和用户反馈后，加入宫位叠加元数据，能否对“用户认为相关的历史记忆”产生额外、稳定的排序收益？

这是针对检索系统的假设。它不等于命盘决定人格，也不把宫位标签视为现实事件的因果解释。

## 对照方案

| 方案 | 信息 |
| --- | --- |
| A | 问题语义与来源内容 |
| B | A + 时间、现实场景与用户明确偏好 |
| C | B + 宫位叠加标签 |
| D | B + 在同一用户内随机打乱的标签 |

各方案应具有相同的候选池、模型预算、历史窗口与评估问题。若 C 无法稳定优于 B、D，就不应把标签结构宣传为有效的个性化增益。

## 数据与判定

- 仅使用用户明确同意参与评估的数据，并允许撤回与删除。
- 以用户对候选记忆的相关性和适用场景的反馈作为标签；不能用系统自身的标签吻合度当作正确答案。
- 按时间划分训练与评估，并报告对新用户的独立检验，避免同一段对话或未来反馈泄漏。
- 预先约定主要指标、样本量分析、无效结果判定与分析代码；不能见到结果后才选择最有利的指标。
- 可报告 nDCG@k、Recall@k、错误偏好引用率与更正处理正确率，并给出按用户聚合的区间估计。
- 记录耗时、检索成本与隐私成本。个别案例或漂亮图谱不能替代整体评估。

## 当前能验证的范围

当前测试只验证时间联动、来源归属、结构校验、视图筛选和追加反馈。真实用户研究、消融实验、偏好学习和模型评测尚未提供。
