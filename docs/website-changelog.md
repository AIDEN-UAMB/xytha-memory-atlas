# Xytha 网站更新记录

完整网站：[xytha.com](https://xytha.com)。这里记录可公开的产品变化；本开源仓库提供独立的合成数据演示，正式网站源码、内部开发记录和核心算法不在公开发布范围内。

## 2026 年 10 月 8 日

### 网站与账号

- 整合主页、研究内容、工作区和最终入口，保留当前视觉风格，关闭风格调试入口。
- 上线邮箱注册、验证、登录与账号恢复流程，更新隐私说明和使用说明。
- 移除正式工作区的示例命盘，用户从自己的资料开始使用。

### 记忆与反馈

- 按账号与命主组织对话及记忆，默认在当前设备浏览器保存。
- 增加用户授权的文件夹镜像、导入导出和导入前恢复；支持的浏览器和明确文件授权是文件夹功能的前提。
- 提供用户反馈入口；对话记忆与反馈采用各自的保存机制。
- 记忆系统打开时默认加载当前时刻，继续保留分层时间选择、再次取消和上级切换清空下级的交互。

### 对话体验

- 修复本轮用量与上下文面板被遮挡的问题，适配桌面和移动端。
- 改善较长历史记录的分页查看和异常附加信息的兼容处理。
- 修复 Nous 紧接着追问时遗漏刚完成回答的历史问题，保留刷新后的命主选择。

### 安全与品牌

- 增强会话与反馈保护、接口访问限制和页面脚本安全策略，更新相关依赖。
- GitHub 标识、演示截图与官网当前 Logo 统一，并提供显眼的完整网站入口。

本次发布经过构建、接口及浏览器回归；涉及模型的回归使用合成测试服务。真实邮件送达和实际模型服务的可用性仍取决于相应服务与用户配置。安全加固不代表能够杜绝所有攻击。

## 更新边界

此记录面向网站使用者，避免披露内部部署位置、密钥、用户数据和保留算法。后续网站发布应同步更新此记录；本开源示例自身的版本变化见 [CHANGELOG](../CHANGELOG.md)。
