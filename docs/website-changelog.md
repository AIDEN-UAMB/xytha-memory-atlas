# Xytha 网站更新记录

完整网站：[xytha.com](https://xytha.com)。这里记录可公开的产品变化；本开源仓库提供独立的合成数据演示，正式网站源码、内部开发记录和核心算法不在公开发布范围内。

## 2026 年 10 月 12 日

- 最新：恢复首页粒子文字、字符涟漪、研究卡片动态与悬停效果，保留图形异常隔离和页面跳转保护；限制大屏画布开销并暂停屏幕外绘制。

- 官网恢复到动态 Logo 实验前的内容基线，并修复图形环境不可用时的首页白屏；装饰效果采用轻量展示，慢速跳转保持当前页面可见。账号、对话和本地记忆逻辑保持原样。
- 后续合并研究稿随本次整版回退撤下，现有文章请从 [Xytha Agent Research](https://xytha.com/research/agent) 浏览。

- 历史发布记录（本次回退后已撤下）：本日比较研究合并稿，八个章节、可交互证据矩阵与图表、可下载数据，保留原稿链接；实测、源码观察和待验证方案分别标注。
- 动态 Logo 设计原型已撤下线上入口，改为仅在本地预览；正式网站标志与研究文章保持不变。

- [Xytha Agent Research](https://xytha.com/research/agent) 独立期刊上线：首批两期四篇，包含设计手记、系统分析、代码体量报告及待执行评估方案。
- 支持期次归档、文章搜索、中英阅读、可交互统计图、数据与引用下载、打印；明确区分已观察数据和待验证假设。

- [在线 Xytha](https://xytha.com) 统一载入反馈：轻量动态提示，完成后淡出，支持减少动态效果。
- 记忆库导入支持按命主预览、匹配合并、范围选择与恢复副本，保留来源和结构化标签。
- 账号内命主标识可单独登记；对话和记忆仍按设备本地保存。

- 客户端 5.0.1 移除网站首页入口，账号、协议和重连返回对话空间；退出后进入登录页。可从[下载页](https://xytha.com/download)覆盖安装更新。

- 记忆读取减少等待和重复刷新，查看已有概述时按需加载原文。
- [下载 Windows / Android 客户端](https://xytha.com/download)，iPhone 可添加到主屏幕；与网站使用同一服务，本地记录可导出、导入迁移。

- 记忆记录移到命盘下方的内嵌滚动区，兼容手机与宽屏。
- 对话整理增加带来源的概述、六层时间和宫位叠加标签；支持确认或修正关联宫位，区分原有依据与主题归类。
- 可用已连接模型精炼概述，保留原始对话；不同命主的记录分别整理。

- 对话消息显示具体日期与时间，采用北京时间。
- 记忆系统加入公历／农历日历，有对话的日期显示标记；点击联动当天命盘和原始记录，不同命主分别查看。
- 私人空间显示邮箱验证状态、注册与最近登录等账号信息，保留密码修改、返回对话和退出入口。

## 2026 年 10 月 8 日

### 网站与账号

- 整合主页、研究内容、工作区和最终入口，保留当前视觉风格，关闭风格调试入口。
- 上线邮箱注册、验证、登录与账号恢复流程，更新隐私说明和使用说明。
- 移除正式工作区的示例命盘，用户从自己的资料开始使用。

### 记忆与反馈

- 按账号与命主组织对话及记忆，默认在当前设备浏览器保存。
- 增加用户授权的文件夹镜像、导入导出和导入前恢复；支持的浏览器和明确文件授权是文件夹功能的前提。
- 提供用户反馈入口；对话记忆与反馈采用各自的保存机制。
- 记忆系统打开时默认加载当前时刻，继续保留分层时间选择、再次取消和上级切换清空下级的交互。

### 对话体验

- 修复空或截断响应触发的 JSON 解析报错；异常读取支持有限重试，保存前先校验完整性。
- 深度分析与个性化聊天兼容空或损坏的历史附加信息，保留原始对话；资料不完整时提供恢复提示。

- 修复本轮用量与上下文面板被遮挡的问题，适配桌面和移动端。
- 改善较长历史记录的分页查看和异常附加信息的兼容处理。
- 修复 Nous 紧接着追问时遗漏刚完成回答的历史问题，保留刷新后的命主选择。

### 安全与品牌

- 增强会话与反馈保护、接口访问限制和页面脚本安全策略，更新相关依赖。
- GitHub 标识、演示截图与官网当前 Logo 统一，并提供显眼的完整网站入口。

本次发布经过构建、接口及浏览器回归；涉及模型的回归使用合成测试服务。真实邮件送达和实际模型服务的可用性仍取决于相应服务与用户配置。安全加固不代表能够杜绝所有攻击。

## 更新边界

此记录面向网站使用者，避免披露内部部署位置、密钥、用户数据和保留算法。后续网站发布应同步更新此记录；本开源示例自身的版本变化见 [CHANGELOG](../CHANGELOG.md)。

## 2026-10-12 · 首页兼容性修复

- 改善不支持图形加速的电脑浏览器兼容性；特效不可用时保留页面内容和入口。
- 修复慢速跳转和返回首页时的可见性恢复，停止失败的动画循环。
- 官网首页异常场景、期刊交互及 Windows/Android 导航回归通过；动态 Logo 设计原型继续仅供本地预览。

## 2026-10-12 · 界面性能优化

- 装饰动画离开视野即暂停，限制绘制频率并合并重复绘制；滚回后自动恢复。
- 研究特效按可见区域加载，鼠标和嵌入演示静止时停止无效更新。
- 保留原有视觉、白屏回退、研究交互和跨端导航；完成公网性能行为与回归验证。

## 2026-10-12 · 首页大屏交互恢复

- 修复大屏鼠标、滚动和点击时字符背景整屏重绘的性能瓶颈，改用缓存和局部更新。
- 增加 4K、高 DPI 和历史全屏设置下的输入、滚动、切换与返回验证，保留页面风格和跨端导航。
- 完成公网回归；此前静止小视口采样不能代表所有交互体验，本次补充相关覆盖。

## 2026-10-12 · 研究卡片交互补充优化

- 消除研究卡片波纹特效首次编译时的长时间同步等待，准备期间页面仍可操作。
- 保持原着色效果，添加静态点阵兼容回退、就绪淡入以及失败/延迟回归检查。
- 保留首屏缓存优化，完成大屏交互与白屏恢复公网验收。
