# Nous-1.0 公开版本说明

Nous-1.0 是为当前第一代执行系统建立的公开版本名。源码中的 `xytha-flow-*`、`bprime.*`、`analysis-plan.*` 等仍是内部协议版本；没有为外观统一而改动这些版本和恢复签名。

## 继承与适配

`SOURCE-MANIFEST.json` 包含每个复制文件的原始和公开 SHA-256。核心导出来自维护时的固定源码快照，生产私有 Git 历史没有被合并进公开仓库。

唯一被适配的运行源码是 `lib/chart-chat-history.ts`：将 Henosis 契约导入替换为相同历史格式常量，以避免牵引 Henosis 实现。历史识别行为保持一致；公开初始化不创建 Henosis 表，也不提供其规划与执行器。

另有一项测试适配：`verify-providers.mjs` 的旧断言预期 GLM 5.2 auto-answer 不发送 thinking，而现有 provider 明确将 answer 设为 disabled。本次修正断言验证保留策略；没有修改 provider 实现。首次失败与后续验证见 `validation.json`。

`runtime/`、`web/`、`scripts/`、类型声明、local-runtime 测试以及本文档是本次新增的独立包装。SQLite 适配和外发地址保护源自现有部署通用模块。没有把安装文档存在但源码缺失的旧命令复制成可运行承诺。

## 范围

| 发布 | 未发布 |
| --- | --- |
| Nous 的执行链及闭合依赖 | Henosis 深度运行时 |
| 排盘、查询、证据契约和修复 | Nous-2.0 尚未确定的实现 |
| Nous 使用的记忆概述提示与检索实现 | 官网完整前端和原生安装包 |
| 数据库结构迁移和本地适配 | 真实数据库及用户记录 |
| 原有协议客户端和合成回归 | 生产认证、密钥、运维和内部完整日志 |
| 来源哈希与公开发布记录 | 私有仓库提交历史 |

此次授权扩大的是 Nous-1.0 公开范围，不将任何未包含的私有实现自动置于 MIT 许可下。原 Memory Atlas 演示保持独立；它的原有无模型运行方式没有改变。

## 可验证而未验证的事项

测试可检查软件计算一致性、输入绑定、恢复行为与来源约束。它们不能证明命理预测、偏好推断有效性、真实模型质量、生产吞吐或跨节点恰好一次语义。发布前的实际验证记录位于 `docs/validation.json`；未执行项必须继续标为未执行。
