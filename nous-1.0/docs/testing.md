# 测试与复现

先运行 `npm ci`、`npm run build`，再运行 `npm run typecheck`、`npm test`、`npm run check`。

`scripts/test.mjs` 顺序执行公开的原始回归，然后验证新的本地宿主。原始回归包含排盘一致性、语义规划、B-Prime 事实与引用门控、调用预算、上下文、时期边界、记忆来源与命主版本、SSE 解析以及供应商协议模拟。Windows ESM 路径兼容器一并公开。

`local-runtime.test.mjs` 启动隔离本机进程，使用临时 SQLite 验证页面、输入限制、跨站拒绝、服务端身份、同请求取回、历史保存和命主间隔离。不向真实供应商发送请求。

`check.mjs` 验证复制文件哈希、源码引用与已知凭据模式。根目录的发布检查另外限定发布路径。模式扫描不是人工审阅或安全审计的替代。

CI 在 Linux / Node 24 上执行独立安装、构建、类型检查和这些测试。Memory Atlas 的静态 Pages 作业仍只上传静态允许列表，不会托管 Node API、运行时数据或模型密钥。

不要把模拟模型测试通过描述成真实模型的准确率提升、速度优势或低成本结论。源码当前没有为 Nous-2.0 提供这些实验结果。
